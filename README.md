# i18nForge MCP Server 🌐🔤⚡

Universal Autonomous App Localization, RTL Arabic & Contextual ICU Translation Engine MCP Server for **Cursor, Claude Code, Windsurf, and Autonomous AI Agents**.

## 🌟 Core Capabilities:
- 👑 **Master 1-Shot Outcome Engine (`autonomous_i18n_localization_and_rtl_architect`):** Ingests UI components or base locale files and delivers a complete multi-language i18n architecture (AR/FR/ES/DE/JA translations, ICU plural tokens, JSX string refactoring, and RTL bidirectional CSS playbook) in one invocation.
- ✂️ **Hardcoded String Extractor (`extract_hardcoded_strings_to_i18n`):** Automatically scans JSX/TSX/HTML, replaces raw text with `t('key')` hooks, and generates clean locale JSON entries.
- 🛡️ **Zero-Corruption ICU Translator (`translate_locale_dictionary_with_icu_safety`):** Translates dictionaries while strictly preserving variables `{user}`, HTML tags `<b>`, and complex ICU pluralization rules.
- 🔄 **Bidirectional RTL CSS Converter (`audit_rtl_bidirectional_css`):** Rewrites directional Tailwind and CSS classes (`left/right`) to logical properties (`start/end`) for flawless Arabic & Hebrew rendering.
- 🔍 **Locale Parity Validator (`sync_and_validate_locale_keys`):** Identifies missing keys and orphan translations across all language files.
